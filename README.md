# WaysGram

Исходный репозиторий клиентского приложения WaysGram.

## Текущий статус

Репозиторий создан как целевое место для Android-клиента. Полный Android-проект пока не загружен: предоставленный архив `Telegram-master.zip` был проверен отдельно и содержит исходный код официального Telegram for Android, а не исходники уникального клиента WaysGram.

Перед сборкой клиент необходимо адаптировать к собственному WaysGram backend и AuthBot. Нельзя оставлять вход через Telegram MTProto, если задача — независимая система с собственной базой данных. Интеграция должна использовать только внутренние виртуальные номера и коды WaysGram из `@AuthWaysGram_bot`; она не должна запрашивать у пользователя реальные коды входа в Telegram.

## Связанные компоненты

- [WaysGram AuthBot и HTTP API](https://github.com/WeteroScript/WaysGram-AuthBot)
- [Аудит исходного ZIP и текущие ограничения](docs/AUDIT.md)

## Зафиксированные требования

- Бренд приложения: WaysGram.
- Исходный интерфейс должен сохраняться без самовольного редизайна.
- Авторизация: виртуальный номер и одноразовый код через `@AuthWaysGram_bot`.
- Сессия приложения хранится на сервере до истечения срока или выхода.
- Пользовательские данные и операции хранятся в собственной SQL-базе AuthBot.
- Новый аккаунт получает 5 000 внутренних Stars и 15 внутренних Gramm один раз.
- Каталог подарков, аукционы, группы и BotFather должны работать через собственный backend.
- Цель первого запуска — локальное тестирование в Termux; затем перенос на VPS.

## Сборка Android

Сборка APK не настроена в этом репозитории, поскольку исходники Android-клиента ещё не перенесены и не адаптированы. Требования к Android SDK/NDK и Gradle для предоставленного Telegram-архива описаны в [аудите](docs/AUDIT.md). APK не публикуется, пока клиент не подключён к WaysGram API и не пройдёт сборку и тестирование.

## Безопасность и конфигурация

Секреты `BOT_TOKEN`, `INTERNAL_API_TOKEN`, `OTP_FERNET_KEY`, ключи подписи APK и серверные пароли нельзя коммитить в Git. Они задаются через локальный `.env` или секреты окружения.
